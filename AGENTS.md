## Project conventions

- Communicate with the user in Brazilian Portuguese. Write technical project artifacts in English.
- When a task depends on the product objective or preliminary scope, consult `README.md` as the source of truth.
- Use only synthetic data for development and testing.
- Present any new requirement or architectural decision as a proposal and obtain human approval before adopting it.
- Obtain human approval before making remote changes.
- Keep credentials and sensitive information confidential. Redact sensitive values from responses, logs, and project artifacts.
